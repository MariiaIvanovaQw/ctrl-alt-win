# Платформа подбора ИТ-специалистов с верифицированным профилем ФСП

Сервис с обратной механикой найма. Кандидат проходит опрос и персональный
тест и получает подтверждённую категорию – IT-направление и грейд.
Работодатель описывает потребность, получает подборку с обоснованием и сам
приглашает конкретного человека, указав вилку зарплаты. Контакты
открываются, только когда кандидат принял приглашение или откликнулся сам.
Профиль связывается с ФСП ID: работодатель видит подтверждённые достижения
соревнований.

## Запуск

Всё в контейнерах (нужен Docker):

```bash
docker compose up --build
```

Веб-приложение – http://localhost:5173, API и Swagger UI –
http://localhost:8000/docs, тестовая почта – http://localhost:8025. При
первом запуске база заполняется демо-данными (около минуты). Учётные
записи:

```bash
docker compose exec api cat /data/demo_accounts.json
```

Без Docker: API – по [backend/README.md](backend/README.md) (Python 3.10+),
веб-приложение – по [frontend/README.md](frontend/README.md) (Node.js 20+).
На странице входа демо-учётные записи подставляются одним кликом.

## Состав

| Каталог | Содержание |
|---|---|
| [`backend/`](backend/README.md) | API на FastAPI: вход в формате Keycloak, профили, тестирование и грейд, подбор с объяснением, приглашения и отклики, задания, ФСП ID, 152-ФЗ; демо-данные, валидация, автотесты |
| [`frontend/`](frontend/README.md) | веб-приложение на React и TypeScript: кабинеты кандидата, работодателя и модератора в фирменном стиле ФСП |
| [`it-assessment-bank/`](it-assessment-bank/README.md) | банк из 720 заданий и алгоритмы: сборка теста по сиду, подсчёт баллов, грейд, валидатор, симулятор |
| [`docs/`](docs/documentation.md) | пояснительная записка (PDF и исходник в Markdown) и спецификация OpenAPI |

## Документация

Пояснительная записка по разделу 3.4 ТЗ – [`docs/documentation.pdf`](docs/documentation.pdf)
(исходник – [`documentation.md`](docs/documentation.md)):
архитектура, механика тестирования и подбора, валидация и её результаты,
интеграция с ФСП, API, компоненты с версиями, запуск, безопасность и
сверка с ТЗ. Спецификация API – [`docs/openapi.json`](docs/openapi.json)
и `/docs` на работающем сервере. Устройство банка заданий –
[`it-assessment-bank/docs/specification.md`](it-assessment-bank/docs/specification.md),
отчёты валидации – [`backend/reports/`](backend/reports).

Пересборка записки (из каталога `backend`): `python -m scripts.build_docs`.

Все люди, компании и достижения в демо-данных вымышлены.
