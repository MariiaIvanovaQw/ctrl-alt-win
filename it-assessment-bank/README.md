# Банк заданий для оценки IT-компетенций

720 заданий (backend, frontend, QA × junior, middle, senior) и эталонная
реализация алгоритмов: сборка персонального теста по сиду, подсчёт
баллов, определение грейда, валидатор качества банка и симуляция
синтетических кандидатов. Python 3.8+, без зависимостей, без сети и без
вычислений в рантайме: эталонные ответы лежат в банке.

**Как подготовлены задания.** ChatGPT Go (OpenAI) составлял промпты, по
которым Claude Opus 5.5 (Anthropic) написал задания: условия, код,
варианты, эталонные ответы, объяснения, разметку компетенций и
сложности. Персональных данных в запросах не было. Каждое задание
проходит проверки V1-V13 и S1-S6; перед эксплуатацией нужна приёмка
практикующими специалистами ([спецификация](docs/specification.md),
раздел 8).

## Команды

```bash
python tools/validate_bank.py                        # статические проверки V1-V13
python tools/simulate_candidates.py                  # проверки на синтетических кандидатах S1-S6
python tools/build_bank.py                           # dist/bank.json и статистика
python tools/build_reports.py                        # отчёты и эталонные примеры в dist/
python tools/assemble_test.py backend middle 184729  # собрать тест по сиду
```

## Как работает

```
сид попытки (64 бита, криптослучайный)
  → assemble_test: 26 заданий по плану уровня, ограничения покрытия, формы и порядок ответов по сиду
  → client_view: кандидат видит только вопрос, код и варианты; ключи остаются на сервере
  → score_attempt: баллы 0/score, итог 0-100, компетенции, полосы сложности, уровень угадывания
  → determine_grade: пороги заявленного уровня, проверка senior → middle → junior, повышение не больше шага
  → категория: specialization + confirmed_level
```

Пороги зависят от заявленного уровня: 70 баллов на тесте junior и на
тесте senior – разные достижения. Общего процента недостаточно: Senior
требует не менее 0,70 баллов на заданиях d7-10, не менее 12 решённых
таких заданий и 0,50 на d9-10. Параметризация – через заранее написанные
формы, поэтому эталон известен и проверка мгновенна.

Правила платформы поверх оценки (понижение – только рекомендация,
интервалы пересдач) реализованы в API: `backend/app/services/assessment.py`.
